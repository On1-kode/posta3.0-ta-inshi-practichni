# Практичні роботи

У корені — роботи з ООП, у папці «Компоненти програмної інженерії» — роботи з цього предмета.

Пошта знаходиться в `Компоненти програмної інженерії/PostServiceSolution`. Із цієї папки запустити сервер:

```powershell
dotnet run --project PostService
```

Вебклієнт: http://localhost:5082, Swagger: http://localhost:5082/swagger.

Для Windows Forms відкрити інший термінал у тій самій папці:

```powershell
dotnet run --project PostService.App
```
