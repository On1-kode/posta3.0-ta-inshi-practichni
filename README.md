## Запуск

Відкрити `Практичні.sln` у Visual Studio з підтримкою .NET 8.

Для консольної роботи, наприклад ПР-47:

```
dotnet run --project ПР-47
```

Для поштового проєкту спочатку запустити сервер:

```
dotnet run --project ПР-46/PostService.Server
```

Вебклієнт: **http://localhost:5080**. Через браузер можна переглядати, додавати, редагувати й видаляти відправлення.

Для Windows-клієнта виконати в іншому вікні:

```
dotnet run --project ПР-46/PostService.WindowsApp
```

Обидва клієнти звертаються до одного API `/postings`. Наприклад, додайте відправлення в браузері й натисніть «Оновити» у Windows-клієнті — воно з’явиться у таблиці.

## Будова поштового проєкту

| Частина | Де розташована | Призначення |
| --- | --- | --- |
| Моделі та узагальнений репозиторій | `ПР-37/PostService.Data` | `Model`, `Posting`, `ContactPerson`, `IRepository<T>` і `GenericRepository<T>` |
| Демонстрація ПР-37 | `ПР-37/Program.cs` | Перевіряє операції зі спільним репозиторієм для двох типів сутностей |
| Сервіс бізнес-логіки | `ПР-46/PostService.Business` | `PostingService` перевіряє дані, викликає репозиторій і формує DTO |
| Сервер | `ПР-46/PostService.Server` | Приймає HTTP-запити й передає їх сервісу; також віддає вебклієнт |
| Windows-клієнт | `ПР-46/PostService.WindowsApp` | Форма списку `PostingList`, форма редагування `PostingEditor` і HTTP-клієнт `PostServiceClient` |
| Вебклієнт | `ПР-46/PostService.WebClient` | HTML-форма, таблиця та JavaScript із запитами до того самого сервера |

Шлях запиту: **Windows-форма або вебсторінка → сервер → PostingService → GenericRepository<Posting>**.

Репозиторій зберігає дані у статичному списку в оперативній пам’яті, як у ПР-37. Після зупинки сервера дані втрачаються. Окремий запуск демонстрації ПР-37 має власну пам’ять процесу.

Windows-клієнт потребує Windows і .NET Desktop Runtime 8. Вебклієнт відкривається у браузері та не потребує окремої збірки. Word-звіти зберігаються окремо від GitHub.

## Перевірка

Перевірка узагальненого репозиторію та бізнес-логіки:

```
dotnet run --project Tests/PostService.Checks
```

Перевірка HTTP-клієнта й API після запуску сервера:

```
dotnet run --project Tests/PostService.Checks -- --server
```

Ручні запити для перевірки кодів відповіді наведено у `ПР-46/postings.rest`.
