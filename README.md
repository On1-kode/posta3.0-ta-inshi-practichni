## Запуск

Відкрити `Практичні.sln` у Visual Studio з підтримкою .NET 8.

Для консольної роботи, наприклад ПР-47:

```
dotnet run --project ПР-47
```

Для ПР-46 спочатку запустити сервер, потім клієнт у другому вікні:

```
dotnet run --project ПР-46/PostService.Server
dotnet run --project ПР-46/PostService.WindowsApp
```

Клієнт ПР-46 працює у Windows. Адреса сервера: http://localhost:5080.
