# Library Search Module

Файл .gan відкривається в GanttProject. План містить 18 робіт у 7 групах, 6 ресурсів і 5 контрольних точок. Робочий календар: понеділок–п’ятниця. Початок 09.11.2026, фінальна віха 10.12.2026.

Залежності finish-to-start задають порядок робіт; розробка фронтенду та бекенду виконується паралельно. У 7.3 за умовою 0,5 дня: через мінімальний крок GanttProject 1 день використано одноденний слот і 50% завантаження менеджера, тобто 0,5 людино-дня.

PDF, короткий звіт і відповіді передаються окремо для Classroom. plan.json містить дані плану для звірки тривалостей і залежностей.
