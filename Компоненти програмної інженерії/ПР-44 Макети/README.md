# Макети PostService

PostService.drawio — редагований файл diagrams.net. Зображення макетів подаються окремо в Classroom і не зберігаються в репозиторії. У редагованому файлі є 16 екранів: 7 для Windows Forms, 7 для вебклієнта й 2 мобільні варіанти.

Червоне поле супроводжується знаком оклику та поясненням; у мобільному варіанті пояснення розташоване під полем. У списку виділено вибраний запис. Для деталей передбачений режим лише читання, для видалення — підтвердження.
