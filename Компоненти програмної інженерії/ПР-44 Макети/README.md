# Макети PostService

PostService.drawio — редагований файл diagrams.net. PNG містить 16 експортованих екранів: 7 для Windows Forms, 7 для вебклієнта й 2 мобільні варіанти. Формат подання — графічні зображення; це макети, а не HTML-сторінка.

Червоне поле супроводжується знаком оклику та поясненням; у мобільному варіанті пояснення розташоване під полем. У списку виділено вибраний запис. Для деталей передбачений режим лише читання, для видалення — підтвердження.
